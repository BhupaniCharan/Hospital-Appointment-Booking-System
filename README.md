# My MERN Health Appointment System

## Overview
This is a full-stack **MERN application** for managing doctor appointments and patient information. The project includes a frontend (React) and a backend (Node.js + Express + MongoDB).

## Features
- User registration and login
- Book, view, and cancel doctor appointments
- Admin and Doctor dashboards
- Patient-related information storage

## Patient Information
The system stores the following patient-related information:
- Name
- Email and Contact Number
- Age and Gender
- Appointment history (doctor, date, time, status)
